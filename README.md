# SpectersAI

Sitio web de SpectersAI — consultoría de automatización e IA para pymes.
Construido con [Next.js](https://nextjs.org) y Tailwind CSS.

Este repo parte como una copia de [specterschile](https://github.com/FabianSerrano7/specterschile)
(specterspro.com) para reutilizar su base (diagnóstico, servicios, quién soy,
FAQ, demo de cliente) mientras se adapta el contenido al nuevo posicionamiento
de automatización e IA.

## Desarrollo local

```bash
npm install
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000) en tu navegador.

## Deploy

El sitio se despliega automáticamente en Vercel con cada push a `main`.
